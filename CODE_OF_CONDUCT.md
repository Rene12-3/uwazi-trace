# Code of conduct

We want a welcoming, evidence-minded community. Be respectful, assume good faith, and critique ideas rather than people.
Do not post accusations about real people or organisations in issues, pull requests or discussions. Contributions that
single out named individuals or groups, or that use sensitive attributes as signals, will be removed.
Report concerns to the maintainers through a private GitHub message. Maintainers may edit or remove contributions that violate this code.
